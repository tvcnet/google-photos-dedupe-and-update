# Support

## Scope

This repository tracks the live unpacked GPTK extension.

The current supported product split is:

- `Scan for Duplicates`
- `Update Photo Albums`

## Before reporting an issue

Please include:

- Chrome version
- whether you loaded GPTK as unpacked
- whether the issue is in `Scan for Duplicates` or `Update Photo Albums`
- whether Gemini or Ollama was selected
- any visible GPTK log lines or browser console errors

## Current limitations

- `Smart Albums` and `Metadata Cleanup` are fully accessible in the toolkit panel in `4.5.0`
- GPTK is tightly coupled to the current Google Photos web UI and may require maintenance when Google changes the page
